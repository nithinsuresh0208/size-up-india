# Size Up India

A daily size-guessing game. Resize the red shape until it matches the real size of an Indian monument, ride or everyday thing, then see how close you were.

- Daily puzzle: 5 rounds, the same for everyone
- Packs: All India, Karnataka, Tamil Nadu, Kerala and Everyday India, 10 rounds each
- Lock-in moment: sound (made in code), score count-up, vibration on Android, confetti on a perfect 100
- Come-back hooks: countdown to the next daily, stats with a score chart, streak flame
- Challenge a friend: a link with the same rounds and your score for each, then a you-vs-them result

A single static `index.html` — no build step. Deployed on Cloudflare Pages.
